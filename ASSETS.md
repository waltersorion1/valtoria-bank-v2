# Asset placement

Final visual assets are not generated by the application. Until supplied, the UI uses a CSS `V` mark and layout-safe neutral treatments.

| Exact path | Format / dimensions | Usage | Variant and fallback |
|---|---|---|---|
| `public/assets/images/brand/logo.svg` | SVG, horizontal, about 180×40 | Light public/app headers | Text wordmark + CSS mark fallback |
| `public/assets/images/brand/logo-light.svg` | SVG, horizontal, about 180×40 | Navy footer/sidebar | White text version; text fallback |
| `public/assets/images/brand/logo-mark.svg` | SVG, square | Compact/mobile navigation | CSS `V` mark fallback |
| `public/assets/images/brand/favicon.ico` | ICO, 32×32 multi-size | Browser favicon | No favicon |
| `public/assets/images/brand/apple-touch-icon.png` | PNG, 180×180 | Apple home-screen icon | No icon |
| `public/assets/images/marketing/home-hero.webp` | WebP, 1600×1200 (4:3) | Optional home hero | Current CSS card composition |
| `public/assets/images/marketing/cards-hero.webp` | WebP, 1600×1000 (8:5) | Cards page | Neutral surface block |
| `public/assets/images/marketing/transfers-hero.webp` | WebP, 1600×1000 | Transfers page | Text-only layout |
| `public/assets/images/marketing/credit-hero.webp` | WebP, 1600×1000 | Credit page | Text-only layout |
| `public/assets/images/marketing/about-office.webp` | WebP, 1600×1067 (3:2) | About page | Neutral surface block |
| `public/assets/images/marketing/security-illustration.webp` | WebP/SVG, 1200×900 | Security page | CSS panel |
| `public/assets/images/placeholders/avatar-default.webp` | WebP, 256×256 | Missing customer avatar | Initials/CSS fallback |

Inherited files under `assets/images/` include Nexus logos, duplicated default avatars, and raster sidebar icons. They remain only for legacy pages during staged migration and should be removed after all references are eliminated. Do not place card PANs, identity documents, customer photos, or screenshots containing personal data in public assets.
